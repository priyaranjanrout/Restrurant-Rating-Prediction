# 🍽️ Restaurant Ratings Predictor

An end-to-end Machine Learning project that predicts restaurant ratings based on restaurant-related features. The project covers data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and deployment using Streamlit.

---

## 📌 Project Overview

Restaurant ratings are influenced by multiple factors such as location, cuisine, pricing, customer preferences, and restaurant services.

This project uses historical restaurant data to build a Machine Learning model capable of predicting restaurant ratings from relevant input features.

The complete workflow includes:

- Data Collection
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Data Visualization
- Machine Learning Model Development
- Model Evaluation
- Streamlit Web Application
- Real-Time Prediction

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze restaurant-related data and identify important patterns.
2. Clean and preprocess raw restaurant data.
3. Perform Exploratory Data Analysis to understand relationships between variables.
4. Engineer relevant features for Machine Learning.
5. Train regression models to predict restaurant ratings.
6. Evaluate model performance using appropriate metrics.
7. Deploy the prediction model through an interactive Streamlit application.
